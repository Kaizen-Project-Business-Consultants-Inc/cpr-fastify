## 1. Security (code review, no exploitation)

### High
- **S-H1** Cross-vendor invoice write via `detected_vendor_id` — `routes/vendors.ts:216-220`. Fix: ignore for role `vendor`, or require `detected[0].id === vendorId`.
- **S-H2** Committed FTP/cPanel credential — `deploy.sh:6-8`; `curl -k` at `:15`. Rotate, remove fallback, purge history (`git filter-repo`), verify GitHub secret scanning.
- **S-H3** Admin can create/promote sysadmin and reset sysadmin passwords — `routes/admin.ts:18,62-63,170,197,204-210,223`. Fix: `sysadminRole` for any request whose target or new role is `sysadmin`/`admin`.

### Medium
- **S-M1** Stored XSS in HTML preview/emails (`PDFService.ts:240-246`, `EmailService.ts:83-125`). Add an `escapeHtml` helper and use it on every interpolation.
- **S-M2** No `trustProxy` (`app.ts:20-24`). Set `trustProxy: true` (or loopback) in production.
- **S-M3** Swagger UI at `/api/v1/docs` public in prod (`routes/index.ts:30`, `plugins/swagger.ts:78-79`). Gate on env or `requireRole('sysadmin')`.
- **S-M4** No refresh-token rotation/revocation; `/logout` lacks `requireAuth` and does not blacklist (`AuthService.ts:93-106`, `routes/auth.ts:116-120`).
- **S-M5** Instructor can read notes on any timesheet — `routes/timesheets.ts:271-280` lacks `instructor_id = ?` (siblings at `:69-71`, `:89-95` have it).
- **S-M6** Access token in URL for the (non-existent) instructor manual — `InstructorLayout.tsx:44-47`. Remove.
- **S-M7** Vendor invoice download authorizes by email string equality (`routes/vendors.ts:304-329`); instructors/students can self-change email with no verification (`instructors.ts:466-476`, `students.ts:60-66`). Use `vendorRole` + `vendor_id = ?`.
- **S-M8** `@fastify/static` 9.1.3 (auth-bypass advisory) and `axios` 1.17.0 (prototype pollution). Static serves only the SPA build with `decorateReply:false`, so exposure is low; upgrade to `@fastify/static@10` and patched axios, run E2E.

### Low
- Blacklist check fails open on DB error (`plugins/auth.ts:38-46`); `text/html` accepted for vendor invoice uploads (never served, latent); `/metrics` unauthenticated; `GET /instructors` (misc) exposes phone/email to any role; CSV export lacks formula-injection neutralisation (`utils/csv.ts:5-14`); JWT algorithm not pinned; admin reset accepts 6-char passwords (`admin.ts:225`) vs 8 elsewhere; `socket.io-client` connects to a `WS_URL` with no server (`useVendorInvoiceUpdates.ts:25`); `vendors.ts:110,239` return raw `err.message` (mysql2 messages contain SQL fragments).

### Already good
100% of non-public routes have `requireAuth`/`requireRole`; fully parameterised SQL including LIKE and pagination; Zod on bodies with whitelisted profile fields (no role/org mass-assignment); org/vendor/instructor scoping consistent except the three cases above; JWT secrets enforced ≥32 chars, no fallbacks, no `.env` tracked; refresh cookie httpOnly/secure/strict/path-scoped; Origin-based CSRF check; CORS pinned; DB-backed lockout (5/15min) and bcrypt 12; upload size/MIME/magic-byte validation with random server names, not web-served; prod error handler hides stack/SQL; no unsanitised `dangerouslySetInnerHTML`; no open redirects; token not in localStorage.
